AIとデータで、新しいサービスをつくる。

Webサービスの企画・開発・運営と、AI・データ活用の研究開発を行う会社です。

事業・サービス

WEB SERVICE

Webサービスの企画・開発・運営

暮らしの相談・案内や情報提供のサービスを、企画から開発・運営まで自社で行っています。小さく始めて、利用者の反応と数字で確かめながら育てています。

R&D

AI・データ活用の研究開発

スポーツ・エンタテインメント・生活の分野を対象に、データ分析とAIを使った予測・判断支援の情報サービスを研究開発しています。

SOFTWARE

制作を自動化するソフトウェアの開発

動画の切り出し・編集・字幕付けの自動化、チャンネル分析、収録支援など、コンテンツ制作の現場で使うシステムを自社開発し、自社と提携先で運用しています。

MEDIA

動画メディアの制作・運営

スポーツ・時事・エンタメ分野の動画メディアをYouTubeを中心に運営しています。自社開発のソフトウェアを実際の現場で検証する場でもあり、運営のノウハウは提携チャンネルの支援にも生かしています。
